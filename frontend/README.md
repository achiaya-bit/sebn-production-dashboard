# SEBN Production Dashboard — Frontend

React 19 / TanStack Start SSR frontend for the SEBN Production Dashboard.

See the [root README](../README.md) for full setup, architecture, and Docker instructions.

## Development

```bash
npm install
npm run dev          # dev server → http://localhost:5173
npm run build        # standard production build
npm run build:docker # Node/Nitro build used by Docker (preset: node-server)
npx tsc --noEmit     # TypeScript check
```
